# VARKA — лендинг обжарочной кофейни

Одностраничный сайт для вымышленной кофейни VARKA (Минск). Сделан без фреймворков
и сборки: чистые HTML, CSS и немного ванильного JavaScript.

## Как посмотреть

Откройте `index.html` двойным кликом — сайт полностью локальный, интернет не нужен
(шрифты подгружаются с Google Fonts, но при их отсутствии используются системные).

Если хочется открыть через локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Структура

```
varka/
├── index.html      разметка: шапка, hero, меню, о нас, обжарка,
│                   атмосфера, отзывы, контакты + форма, подвал
├── styles.css      дизайн-система (палитра, типографика, сетки, адаптив)
├── script.js       мобильное меню, табы, анимации появления, форма
└── img/            фотографии (5 шт., локальные)
```

## Что уже работает

- **Меню с табами** — «Кофе», «Не кофе», «К зерну»; переключение мышью и стрелками с клавиатуры.
- **Мобильное меню** — бургер, закрытие по Escape и клику вне панели.
- **Плавные появления секций** при скролле (IntersectionObserver).
- **Подсветка активного раздела** в навигации.
- **Форма брони** — проверка имени, телефона, даты и времени, экран подтверждения.
- **Адаптив** — проверено на 1440, 900 и 390 px.
- **Доступность** — семантическая разметка, focus-состояния, `prefers-reduced-motion`,
  alt-тексты, aria-атрибуты для табов и меню.

## Дизайн

- Палитра: тёплый бумажный фон `#f4eadd`, эспрессо `#1f1611`, клэй-акцент `#c05f35`, золото `#d9a45f`.
- Заголовки — Playfair Display, текст — Manrope.
- Иллюстрация чашки в hero — встроенный SVG (без картинок), пар анимирован.
- Бегущая строка, «бумажное зерно» поверх страницы, наклонные карточки-стикеры.

## Что стоит заменить перед реальным запуском

- Телефон, адрес, почта и ссылки на соцсети — сейчас демонстрационные заглушки.
- Форма ничего не отправляет: подтверждение показывается на клиенте.
  Для приёма заявок подключите бэкенд или сервис вроде Formspree.
- Фотографии взяты с Unsplash (бесплатная лицензия) как временные — лучше заменить
  на съёмку вашей кофейни.
